# 迦南團契｜十月查經網頁

**經文：** 以弗所書 1:1–14  
**主題：** 神萬世以前的揀選與基業｜《十架更新，憑信同行》  
**標記：** 十月查經（無後端；答案與經文標記僅存本裝置瀏覽器 localStorage）

**線上組員頁：** https://bzwt6ck9tn-lang.github.io/canaan-bible-study/member.html?v=20261001b

## 檔案

| 檔案 | 說明 |
|------|------|
| `index.html` | 簡單入口：組員頁／組長頁 |
| `member.html` | 組員專用內容：經文、觀察／解釋題、帶走、本週小改變；不含建議答案或流程卡 |
| `leader.html` | 組長專用內容：同一套問題、可展開建議答案、流程卡與引導用語 |
| `styles.css` | 手機優先共用樣式 |
| `app.js` | 兩個內容頁共用的答案儲存／清除與經文點按標記功能 |

## 如何開啟

在 `canaan-bs-web` 目錄執行：

```bash
cd /workspace/canaan-bs-web
python3 -m http.server 8765
```

然後開啟：

```text
http://127.0.0.1:8765/
```

組員請只用 `member.html`；組長請用 `leader.html`。點按經文短句可切換黃色標記，再點一次取消；標記可用經文旁的「清除標記」按鈕全部移除。答案、本週小改變勾選、填寫記錄與經文標記只儲存在此裝置的瀏覽器，不會上傳或同步。

## 使用限制

- 無帳號、無雲端同步、無多人共用答案。
- 清除瀏覽器網站資料即失去答案。
- 建議答案僅供組長備課，不是要組員背誦的標準答案。
